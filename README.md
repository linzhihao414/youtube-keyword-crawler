# YouTube Keyword Crawler

Search YouTube by keywords, collect video and channel info, export to Excel.

## Quick Start

1. Edit `keywords.txt` with your search terms (comma separated)
2. Double-click `run.bat`
3. Results saved in `output/` folder

## What it collects

- Video title, URL, views, likes, comments, duration
- Channel name, channel URL
- Upload date, description

No API key needed. Uses yt-dlp.
